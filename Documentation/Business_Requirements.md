# Business Requirements

## Project Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on a curated SQL Server Data Warehouse to generate actionable business insights.

The project supports decision-making by analyzing customer behavior, product performance, and sales trends using analytical SQL queries.

---

# Business Goals

The analysis should help stakeholders answer the following questions:

- Which customers generate the highest revenue?
- Which products contribute most to sales?
- Which product categories perform best?
- Which countries generate the highest revenue?
- How have sales changed over time?
- What is the average order value?
- Which products require business attention?
- Which customers should be targeted for retention?

---

# Functional Requirements

The SQL scripts should:

- Explore the database structure.
- Analyze dimension tables.
- Calculate key business KPIs.
- Measure sales performance.
- Rank customers and products.
- Answer real-world business questions.

---

# Non-Functional Requirements

- Queries should be readable and maintainable.
- SQL should follow best practices.
- Results should be reproducible.
- Analysis should be easy to extend.
- Documentation should be clear for technical and business users.

---

# Expected Deliverables

- SQL Scripts
- Business Insights
- Documentation
- GitHub Repository
