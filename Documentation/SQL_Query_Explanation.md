# SQL Query Explanation

This project is organized into multiple SQL modules.

---

# 01 Database Exploration

Purpose:

Explore the database metadata.

Key SQL Concepts:

- INFORMATION_SCHEMA
- COUNT
- ORDER BY

---

# 02 Dimension Exploration

Purpose:

Analyze descriptive business dimensions.

Tables:

- dim_customers
- dim_products

Key SQL Concepts:

- DISTINCT
- GROUP BY

---

# 03 Date Exploration

Purpose:

Analyze sales across time.

Key SQL Concepts:

- MIN()
- MAX()
- YEAR()
- MONTH()

---

# 04 Measure Exploration

Purpose:

Calculate business KPIs.

Examples:

- Total Sales
- Total Orders
- Average Sales

Key SQL Concepts:

- SUM()
- AVG()
- COUNT()

---

# 05 Magnitude Analysis

Purpose:

Compare sales across dimensions.

Key SQL Concepts:

- GROUP BY
- SUM()
- ORDER BY

---

# 06 Ranking Analysis

Purpose:

Rank business entities.

Key SQL Concepts:

- ROW_NUMBER()
- RANK()

# 07 Business Questions

Solve practical business problems using SQL.
